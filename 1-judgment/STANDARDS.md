# STANDARDS — 判别标准(UI 任务必读,一页封顶)

> 来源:Awwwards 官方权重 / Vercel Geist / Material 3 / Stripe / Apple HIG / NN/g / WCAG,
> 出处见 research/02。行业对"好"的定价:**视觉执行 40% + 可用性 30% + 创意 20% + 内容 10%** —— 基本功占七成,先把下面做对,再谈炫。

## 1. 层级 Hierarchy
- 一屏内容分明确的 3 层(主/次/辅),用**大小+重量+灰度**至少两个杠杆拉开
- 主 CTA 全屏唯一实心;次按钮 ghost/text 化。两个同样式按钮并排 = 违规
- 大标题 `clamp(32px, 5vw, 64px)`,与正文字号比 ≥ 2:1

## 2. 间距 Spacing
- 只用音阶:`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96`(px)。任何不在音阶上的间距 = 违规
- 亲密性:组内间距 ≤ 组间间距的 1/2;相关元素(标题+其副文)≤8px
- 区块节奏要有变化:全页每个 section 同 padding = 模板感

## 3. 字体 Typography
- 字号走音阶(如 12/13.5/15/17/20/24/32/48);字重只用 400/450/500/600/750±
- **字号-字重反向补偿(核心法则,Vercel 实证)**:字号越大字重越轻,字号越小字重越重——大字号本身视觉重量已够,小字号靠字重补足存在感。实测 vercel.com:H1 64px→400 / H2 56px→450 / 按钮 14px→500 / 小标签大写 14px→600。**推论:小字号导航/标签"太细"的解法是加字重(→500/600),不是加字号。**
- **可变字体优先**:连续字重(400-600 无级)才能做上面的精细补偿。Geist(Vercel)是可变字体;中文要具备此能力必须选思源/MiSans(可变或多字重),系统微软雅黑不行。
- **中文字重的物理约束**:中文是方块字、笔画密度高,同字号视觉重量>拉丁→字重舒适区窄(正文 400-500,600+ 易糊);微软雅黑只有 400/700 两档、无 500/600 中间档→想精细加粗**必须换连续字重中文字体**(这是"太细却加不上去"的物理根因,不是审美问题)。
- 大标题(≥32px)字距收紧 `-0.02em ~ -0.06em`(Vercel H1 实测 -0.06em、行高 1.0);小标签放宽 `+0.04em~0.1em` 并配大写——**等宽字(mono)做全大写小标题是高级签名手法**(Vercel 反复用)
- 正文 15-18px、行高 1.6-1.75、行宽 45-75ch;标题行高 1.0-1.3
- display 字体禁止 Inter/系统栈单打(正文可以);中文界面注意中西文混排基线
- 全 bold = 等于没 bold:重量是层级工具,不是装饰。但"不用字重"也是错——见反向补偿法则,字重要按字号系统性分配

## 4. 颜色 Color
- 层次交给灰阶(参考 Geist:近黑 `#171717` 文字 / 近白 `#fafafa` 底 / 灰阶分 2-3 档次级信息)
- **一个强调色,一屏 ≤3 处**。第二个彩色出现必须有功能理由(如语义色 success/error)
- 文字对比度 ≥4.5:1(WCAG AA);彩底白字必查
- 背景要有微深度(细渐变/噪点/浅灰分区),纯 #FFF 或 #000 大平面易显裸

## 5. 深度 Depth
- 默认:`1px solid` 边框 + `0 1px 2px rgba(0,0,0,.04)` 微影;深度靠底色差分层
- 大阴影(blur >16px)仅限 hero 级悬浮元素,一屏 ≤1 处;光源方向全站一致
- 圆角全站 ≤2 档(如 6px 控件 + 12px 容器),禁逐元素随机

## 6. 动效 Motion
- UI 动效 **150-400ms**;入场 decelerate(`cubic-bezier(0.2,0,0,1)` / ease-out),出场 accelerate
- 组进场 stagger 50-80ms;位移幅度 ≤16px(大位移=廉价)
- **高频操作(菜单/切换/tooltip)<150ms 或不加动画** —— 每天用几百次的东西,动画是负担
- 只 animate `transform` + `opacity`(Stripe 铁律);`prefers-reduced-motion` 必须响应
- 感知延迟:操作反馈 <100ms;>1s 必须有 loading 态(Doherty 阈值 400ms)

## 7. 状态 States
- 交互元素四态齐全:`hover / focus-visible / active / disabled`(focus 环是无障碍必需,最常漏)
- 数据区三态齐全:`loading(骨架) / empty(引导) / error(可恢复)`
- 乐观 UI:本地可预测的操作先响应再同步

## 8. 自洽 Coherence
- 色/字/距/形/动五维讲同一个故事;风格混搭最多"主 1 + 局部 1"
- 每个元素问一句:它像不像这一家的?外来感元素 = 违规
- 有观点:文案用具体主张和数字,布局敢不对称,整页留 1-2 处签名时刻(其余克制)
