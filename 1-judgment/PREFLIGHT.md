# PREFLIGHT — 出厂自检(交付前必跑,浏览器实测不是脑测)

> 流程:起本地服务 → Playwright 打开 → 截图 375 / 768 / 1440 三档宽度 →
> 逐组对照下表 → 列出问题清单 → 逐项修 → 复截确认 → 才允许给用户看。
> 口径:每项 PASS / FAIL / N.A.,FAIL 必须修或明说原因。

## A. 排版(对照 STANDARDS §1-3)
- [ ] 一屏层级 ≤3 层,主 CTA 全屏唯一实心
- [ ] 所有间距在音阶上(4/8/12/16/24/32/48/64/96)
- [ ] 大标题字距已收紧;正文行高 1.6-1.75;行宽 ≤75ch
- [ ] 无孤行(标题最后一行只剩 1 个词)

## B. 颜色(§4)
- [ ] 强调色一屏 ≤3 处;层次由灰阶承担
- [ ] 文字对比度 ≥4.5:1(彩底白字逐个查)
- [ ] 无 AI-TELLS 视觉禁令项(紫渐变/渐变字/emoji 图标…)

## C. 深度与自洽(§5、§8)
- [ ] 深度=1px 边框+微影;大阴影一屏 ≤1 处;光源一致
- [ ] 圆角全站 ≤2 档;字系 ≤2
- [ ] 逐区块扫一遍:有没有"外来感"元素

## D. 动效(§6)
- [ ] UI 过渡 150-400ms、decelerate 入场;无 linear
- [ ] 组进场有 stagger(50-80ms);位移 ≤16px
- [ ] 高频操作 <150ms 或无动画;无无限循环乞讨动画
- [ ] 只 animate transform/opacity;`prefers-reduced-motion` 已响应

## E. 状态(§7)
- [ ] 交互元素四态:hover / focus-visible / active / disabled(Tab 一遍键盘)
- [ ] 数据区三态:loading(骨架)/ empty / error
- [ ] 点击反馈 <100ms;耗时操作有进行中态

## F. 响应式
- [ ] 375px:无横向溢出、无文字挤压、可点目标 ≥44px
- [ ] 768px:栅格正确塌缩(4→2→1)
- [ ] 1440px:内容有 max-width 约束,不无限拉伸

## G. 内容与表达
- [ ] 文案无 AI 套话;至少一句只有这个产品能说的话
- [ ] 图片/素材无占位感(有就换生成素材或删)
- [ ] 有且只有 1-2 处签名时刻

## H. 性能
- [ ] 无 >200KB 单资源;图片 lazy;动画不引发 layout(DevTools 看一眼)
- [ ] backdrop-filter 可见范围 ≤5 处
