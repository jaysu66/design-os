# 沟通速查卡(贴手边那份)

## 开工公式(4 句话)

1. **表达什么**:页面想让人记住的一句话
2. **给谁看**:目标读者 + 打开场景
3. **参考**:丢 1 个链接;没有就说"从参考库挑 3 个给我"
4. **绝对不要**:你的黑名单(哪怕只有一条)

> 例:"做 Acme 官网。表达'企业级 AI 工作台,可靠不花哨';给 CTO 看;
> 参考这个站的克制感(链接);绝对不要紫色渐变。"

## 反馈公式(位置 + 问题 + 方向)

- **位置**:哪个区块哪个元素 —— "首屏主标题"
- **问题**:用下面翻译表的词 —— "压不住场,层级太平"
- **方向**(可选):大致往哪调 —— "再大再重,字距收紧"

**要点:说出问题就够,解法让 agent 提。最忌"不好看,重做" —— 等于让它重新抽签。**

## 直觉 → 词汇翻译表

| 你的直觉 | 大概率问题 | 对 agent 说 |
|---|---|---|
| 感觉乱 | 层级/间距 | 层级拉开主次;间距统一到 8 的倍数,相关元素收紧成组 |
| 感觉廉价 | 阴影/颜色/字距 | 大阴影换 1px 边框;砍到一个强调色;标题字距收紧 |
| 感觉挤 | 留白不足 | 区块间距升一档,给内容呼吸感 |
| 感觉空/单薄 | 层次不足 | 加灰阶层次和 1px 分隔,不要加颜色 |
| 太花了 | 动效/颜色过量 | 动效降档只留一处,颜色回归灰阶 |
| 像 AI 做的 | 默认值堆积 | 去模板脸:文案换具体数字,布局去居中,删 emoji 图标 |
| 没记忆点 | 缺签名时刻 | 给一处签名时刻,其余保持克制 |
| 死板/像贴图 | 状态缺失 | 补全 hover/focus/active/disabled + loading/empty |
| 不像一家人 | 自洽碎了 | 统一设计语言:同字系、同圆角、同灰阶 |
| "高级一点" | 太抽象 ⚠️ | 换成:参考 ××站(丢链接),学它的 ××(哪一点) |

## 万能钥匙(说不清的时候)

> "对照 DESIGN.md 和自检清单,列出这页最明显的 5 个问题,再逐项修。"

## 十个概念的一句话版(详见 审美训练.html)

1. **层级**:眼睛该被安排先看什么后看什么 —— 大小/粗细/深浅/位置四个杠杆
2. **间距**:只用 4/8/12/16/24/32/48/64;相关的靠近,无关的远离
3. **字体**:大标题收字距(-0.03em);正文行高 1.6-1.75;一行 ≤65 字符;别全加粗
4. **颜色**:层次交给灰阶;一个强调色,一屏 ≤3 处
5. **深度**:1px 边框 + 微影,不要大黑影
6. **动效**:150-400ms、ease-out、错峰;高频操作不加动画
7. **状态**:交互元素四态(hover/focus/active/disabled)+ 数据区三态(loading/empty/error)
8. **自洽**:色字距形动五维讲同一个故事
9. **AI 味**:居中 hero+渐变字+三卡+emoji+套话 = 模板脸,是"谁都不是"
10. **签名**:整页 1-2 处记忆点,克制是签名的前提
