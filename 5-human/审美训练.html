看得出,说得出

10 个概念,把你的直觉变成 agent 能执行的词汇。你不需要会做设计 —— 你是创意总监,agent 是设计师。总监的本事只有两样:看出哪里不对,说出哪里不对。每一节:先看两个例子哪个舒服(校准直觉),再读差异点(获得词汇),记住那句话(下次直接说)。

① 层级② 间距③ 字体④ 颜色⑤ 深度⑥ 动效⑦ 状态⑧ 自洽⑨ AI 味⑩ 签名速查表
01 · HIERARCHY

视觉层级

一屏之内,眼睛应该被安排好先看什么、后看什么。工具只有四个:大小、粗细、颜色深浅、位置。"感觉乱"十有八九是层级平了。

BAD · 全都一样重

Pulse 数据平台

实时看清你产品的每一次心跳

GOOD · 一眼三层

看清产品的每一次心跳

Pulse 把埋点、看板和告警放进同一张画布,五分钟接入。

  • 标题、副标题、按钮字号重量全部接近
  • 两个按钮同样式 —— 没告诉我该点哪个
  • 大 → 中 → 小三层,一眼扫完
  • 主按钮实心、次按钮幽灵化:重要性有排序
你该说"层级太平了,我找不到重点 —— 标题压不住场,把主次拉开;两个按钮分出主次。"
02 · SPACING

间距与节奏

间距只用固定音阶(4 / 8 / 12 / 16 / 24 / 32 / 48 / 64),且相关的靠近,无关的远离(亲密性)。间距随机 = 廉价感的头号来源。

GOOD · 音阶 + 亲密性

03 · TYPOGRAPHY

字体排印

字号走音阶、大标题收紧字距(约 -0.03em)、正文行高 1.6-1.75、一行别超 65 字符。全加粗 = 等于没加粗。

BAD · 全 bold + 行宽失控

颜色

层次交给灰阶,彩色只留一个强调色、且一屏出现 ≤ 3 处。颜色越多,每个颜色越不值钱。

深度与材质

高级产品用 1px 边框 + 极轻阴影建立深度,而不是大黑影。阴影越重越像 2015 年的模板。

06 · MOTION

动效

UI 动效 150–400ms、先快后慢(ease-out)、逐个错峰(stagger)。匀速(linear)是机器感,超 400ms 是拖沓,全体同时飞是廉价。点两边的「重放」对比感受。

BAD · 1.4s 匀速弹跳飞入
📈 转化率 4.2%
👥 活跃用户 18,204
⚡ 平均响应 213ms
GOOD · 240ms ease-out 错峰
转化率 4.2%
活跃用户 18,204
平均响应 213ms
  • 1.4 秒 + 弹跳 + 旋转:动画本身成了主角
  • 三项同时起跳,没有先后叙事
  • 240ms、位移只有 12px:感觉"内容自己落定"
  • 每项错峰 60ms:有节奏,但不耽误你干活
你该说"动效降到 300ms 以内、ease-out、错峰进场;高频操作(菜单/切换)不要加动画。"
07 · STATES

状态完整性

每个可交互元素都欠你四个状态:hover / focus / active / disabled;每个数据区欠你三个:loading / empty / error。AI 最常只交付"静止的完美"。用鼠标悬停、按 Tab、点按试试下面两边。

BAD · 只有一种状态
悬停、Tab、点按 —— 毫无反应,像贴图。
GOOD · 状态齐全
hover 微升、Tab 有 focus 环、按下有回压、禁用有灰态、加载有骨架。
  • 无 hover / focus / active:用户的每次操作都得不到回应
  • loading 与 empty 没设计:数据一慢页面就"裸奔"
  • 四态齐全,键盘用户也有 focus 环(无障碍必需)
  • 骨架屏占位:慢的时候也体面
你该说"把状态补全:hover/focus/active/disabled 四态,数据区加 loading 骨架、empty 和 error 态。"

自洽:讲同一个故事

10 · SIGNATURE

签名时刻

整页留 1–2 处让人记住的细节,其余全部克制 —— 克制是签名的前提,处处惊喜等于没有惊喜。

GOOD · 全页唯一的"活物"(把鼠标移近按钮)
这颗按钮会被鼠标轻轻"吸住" —— 因为整页只有它会,你才记得住它。如果每个元素都在动,它就消失了。
你该说"整页给我留一个签名时刻(一处特别的交互或视觉),其他地方全部收着做。"

直觉 → 词汇速查表

感觉说不清的时候,按左列找到你的直觉,照右列开口。

你的直觉大概率问题对 agent 说
"感觉乱"层级 / 间距层级拉开,主次分明 间距统一到 8 的倍数,相关的收紧成组
"感觉廉价"阴影 / 颜色 / 字距大阴影换 1px 边框 砍到一个强调色 标题字距收紧
"感觉挤"留白不足区块间距升一档,给内容呼吸感
"感觉空/单薄"层次不足加灰阶层次和 1px 分隔,不要加颜色
"太花了"动效/颜色过量动效降档只留一处,颜色回归灰阶
"像 AI 做的"默认值堆积去模板脸:文案换具体数字,布局去居中,删 emoji 图标
"没记忆点"缺签名时刻给一处签名时刻,其余保持克制
"死板/像贴图"状态缺失补全 hover/focus/active/disabled + loading/empty
"不像一家人"自洽碎了统一设计语言:同字系同圆角同灰阶
"高级一点"(慎用)方向太抽象像 Linear/Stripe 那样 × → 换成 参考 XX 站(丢链接),学它的 YY

开工公式(给 brief,4 句话)

  1. 表达什么:这个页面想让人记住的一句话
  2. 给谁看:目标读者是谁、在什么场景打开
  3. 参考:丢 1 个链接(没有就让 agent 从参考库出 3 个候选给你挑)
  4. 绝对不要:你的黑名单(哪怕只有一条)

例:"做 Acme 官网。表达'企业级 AI 工作台,可靠不花哨';给 CTO 看;参考这个站的克制感(链接);绝对不要紫色渐变。"

反馈公式(位置 + 问题 + 方向)

  1. 位置:哪个区块哪个元素("首屏主标题")
  2. 问题:用速查表的词汇("压不住场,层级太平")
  3. 方向(可选):大致往哪调("再大再重,字距收紧")

要点:说出问题就够了,解法让 agent 提。最忌只说"不好看,重做" —— 那等于让它重新抽签。
