# DESIGN-TEMPLATE — 项目设计指南针模板

> 每个项目一份,存项目根目录 `DESIGN.md`,**一页封顶**。agent 做该项目任何 UI 工作前必读。
> 生成时机:入口①第 4 步;用户点头后才生效。写给 agent 执行,不堆术语。

```markdown
# DESIGN — <项目名> 设计指南针
> 生成 <日期> · 参考已用户确认 · 改动需用户点头

## 1. 表达(一句话)
这个界面要让人记住:<……>。看完的人应该觉得:<……>。

## 2. 受众与场景
给 <谁> 看;typically 在 <什么设备/什么心情> 下打开。

## 3. 参考绑定
- 主参考:<名字/路径>(学:整体气质、色彩策略、密度)
- 局部参考:<名字>(只学:<首屏布局/字体处理/动效,选一>)
- 不学:所有参考的品牌资产(logo/文案/图片)一律不碰

## 4. 气质三词
<例:冷静 · 精密 · 克制>(拿不准时,任何决策向这三个词对齐)

## 5. 色彩 tokens
- 底:<#>  面:<#>  文字主/次/辅:<#/#/#>
- 强调色:<#>(一屏 ≤3 处;仅用于:主 CTA / <…>)
- 语义色:success <#> / error <#>
- 禁用:<例:任何渐变、紫色系>

## 6. 字体
- Display:<字体>(标题 ≥32px 字距 <-0.0Xem>)
- 正文:<字体> 15-17px / 行高 1.65 / 行宽 ≤70ch
- 字重只用:<400/500/650>

## 7. 空间与密度
- 间距音阶:4/8/12/16/24/32/48/64
- 密度:<紧凑工具型 / 舒展叙事型>;圆角两档:<Xpx 控件 / Ypx 容器>
- 深度:1px 边框 + 微影;大阴影仅 <哪里> 允许

## 8. 动效档位
- 档位:<1 静态克制 / 2 标准(默认) / 3 叙事增强>
- 参数:入场 240ms decelerate + stagger 60ms;高频 <120ms
- 签名时刻(全站 1-2 处):<在哪里,做什么>

## 9. 本项目绝不(负面清单,优先级最高)
- <用户说过的绝对不要>
- <参考里明确不学的>
- AI-TELLS 全文默认生效
```
